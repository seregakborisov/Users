1. Объединить старое и новое fastapi приложение (main + main_2)
2. Вынести модель пользователя в бд. Остальные модели можно удалить (т.к. этот сервис отвечает чисто за пользователей, можно закомментить их на будущее.)
3. Добавить модели пользователя пароль. Хранить пароль в бд (захешировать перед сохранением).
4. При авторизации, регистрации - использовать данные из бд.
5. Всё закоменченное вынести в папку old (можно создать отдельный файл-свалку).
6. Только для админа добавить возможность чтения списка пользователей, и удаление пользователей (is_active = false).
7. Обычный пользователь должен иметь возможность посмотреть информацию о себе (`/self`)
8. Если пользователь не активен - он не может залогиниться и посмотреть информацию о себе.
9. Админ может редактировать других пользователей и ставить им is_admin = true/false.
10. Обычный пользователь может редактировать только своё имя.
